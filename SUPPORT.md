# Support

## Supported docs

- **The website:** [wasmcloud.com](https://wasmcloud.com) is deployed from `main`. Its current docs
  cover the latest wasmCloud release. Fixes land on `main` and go live when they merge.
- **Offline docs:** each `docs-vX.Y.Z` release, an offline tarball and the `ghcr.io/wasmcloud/docs`
  image, matches the wasmCloud release of the same version. Only the release matching the latest
  wasmCloud release is supported, following the
  [wasmCloud support policy](https://github.com/wasmCloud/wasmCloud/blob/main/SUPPORT.md).
- **Fixes to the offline docs:** a fix ships in the next docs release. Earlier docs releases aren't
  updated.
- **Archived docs:** the docs for wasmCloud 1.x and 0.82 are kept on the site for reference. They
  are no longer updated.

## Getting help

- Ask questions in [Slack](https://slack.wasmcloud.com/) or bring them to a
  [community meeting](https://wasmcloud.com/community/).
- Report problems with the docs or the site as
  [GitHub issues](https://github.com/wasmCloud/wasmcloud.com/issues), and problems with wasmCloud
  itself in [wasmCloud/wasmCloud](https://github.com/wasmCloud/wasmCloud/issues).
- Report security vulnerabilities privately, as described in the
  [security policy](https://github.com/wasmCloud/wasmcloud.com/security/policy).

Support is provided by the community on a best-effort basis.
